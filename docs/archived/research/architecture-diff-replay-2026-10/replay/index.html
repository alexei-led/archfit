Методика и ограничения
  • Все closed PR пагинированы; выбраны последние 20 merged каждого repository по merged_at. Без topic filtering.
  • Окна: archfit 27–29 октября; ccgram 21–29 октября 2026. В основном один owner, не годовой multi-team experiment.
  • 20 captured archfit/state checks neutral, 6 action_required, 14 без подходящего completed final-head check. Это не 40 fully-green PR.
  • Final merged patches уже содержат fixes из review. Уже пойманные ошибки не новые misses.
  • Issue comments edited после merge исключены. PR bodies mutable, не historical ground truth.
  • Два больших PR (287 и 246 files) reviewed selectively. Не полный bug audit.
  • Пять archived CI reports; один regression reproduced на двух исторических binaries. Все 40 analyzer environments не rerun.
  • Jev/Clef не запускались. Human review speed, accuracy и willingness to pay не измерены.
  • Не подтверждён новый missed defect как prospective успех именно proposed boundary diff.
WHERE CLASSIFIERS COULD HELP

Объяснять преобразование, не фильтровать истину.

#341: private state → runtime callback. #350: UI responsibility → narrow adapter. Jev/Clef можно проверить на transformation classification и выборе investigation. Source tools устанавливают facts; tests проверяют behavioral contracts.

#342 и #363 не требуют model inference. Scope и measurement identity достаточны. Blockers и missing evidence нельзя скрывать.

Первый increment: улучшить существующий feedback. Classifier должен превзойти deterministic templates на реальных случаях — не просто звучать убедительнее.
