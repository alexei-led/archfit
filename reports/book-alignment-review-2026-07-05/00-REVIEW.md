## 1. Verdict

**Short verdict.** archfit now implements the **deterministic Ch7–Ch10 Balanced Coupling core well**: the book score is verbatim, the gate is reproducible, same-module/local complexity is separated from cross-boundary balance, and the tool abstains honestly when it cannot measure. It is **not yet a complete practical automation of the whole book** because connascence is not first-class, runtime distance is report-only, clone-only duplicated knowledge is outside the flagship score, and the semantic/LLM evidence pack is still thin.

- **Book-conformance score:** **4.2 / 5**
- **Practical-tool score:** **3.8 / 5**

Why the score is not higher:

1. **Connascence is only implicit.** Strength uses connascence ideas, but archfit does not report or score Ch6 degrees directly.
2. **Distance is adapted, not complete.** `D=9` and `D=10` are present, but `D=8` (“different libraries”) is not a first-class measured rung, and runtime coupling stays report-only.
3. **Semantic input is reviewable but shallow.** Off-gate LLM flows are structurally separated, but `config init --llm` and `config update --llm` still feed mostly paths, globs, file basenames, and Markdown headings.
4. **One core book case is still outside the flagship score.** Clone-only duplicated knowledge is detected and scored, but kept out of `coupling_balance` and `coupling.gate`.

## 5. Deterministic vs semantic split

### 5.1 Facts that must stay deterministic

These should remain machine-derived and reproducible at analysis time:

- **Import / reference / dependency edges** — Go `go/packages`, TS `dependency-cruiser`, Python `grimp`, Rust `cargo metadata` / `cargo-modules`. `internal/extract/golang/golang.go:77-258`; `internal/extract/ts/ts.go:77-181,542-686`; `internal/extract/py/py.go:71-176,403-484`; `internal/extract/rust/rust.go:75-178`; `internal/extract/rust/modules.go:22-104`.
- **Strength hints from syntax / type facts** — object kinds, type-only imports, private-module access, clone pairs, approved labels. `internal/extract/golang/golang.go:338-375`; `internal/extract/ts/ts.go:519-531`; `internal/extract/py/py.go:436-456`; `internal/classify/classify.go:390-409,541-591`.
- **Distance composition** — same-module, structure, owner, deploy unit, declared external seams. `internal/classify/classify.go:637-704`; `internal/classify/distance_structure.go:11-209`; `internal/classify/external_systems.go:11-56`.
- **Score math and bands** — ordinals, `ScoreVersion`, `ScoreBand`, score rescale, confidence caps, `n/a` honesty. `internal/model/coupling/scorer.go:10-30,143-155`; `internal/model/coupling/scorer_book.go:23-123`; `internal/score/score_boundary_coupling.go:30-166`; `internal/score/score.go:83-131`.
- **Gate behavior** — `min_band`, `max_drop`, promotion to gate findings, baseline-version handling. `internal/score/gate.go:19-57`; `cmd/archfit/pipeline_run.go:463-533`; `cmd/archfit/analyze.go:193-212`.
- **Report-only isolation** — `runtime_async`, `local_coupling`, declared complementary metrics. `internal/engine/local_coupling.go:17-109`; `internal/engine/engine_test.go:2155-2183`; `internal/metrics/metrics.go:49-66`.

### 5.2 Facts that need semantic judgment, but must become pinned deterministic input before affecting score

These are legitimate LLM / reviewer tasks, but **not** live score overrides:

- **Module role / subdomain / volatility / owner meaning.** `cmd/archfit/init.go:155-166`; `cmd/archfit/update.go:302-349`; `cmd/archfit/enrich.go:196-347`.
- **Abstained strength labels.** LLM-provenance labels only fill cells static evidence left unknown, then must be approved and freshness-checked. `internal/labels/labels.go:12-20,64-69,109-184`.
- **Architecture intent from ADRs / docs / comments.** Current prompts read too little of that material. `cmd/archfit/init.go:155-193`; `cmd/archfit/update.go:300-349`; `internal/initcfg/classify_targets.go:27-58`.
- **Narrative review / prioritization / top-risk phrasing.** Must stay advisory and post-verified against deterministic evidence. `cmd/archfit/llmreview.go:56-98,139-166,260-448`.
- **Single-finding explanations.** `cmd/archfit/explain.go:18-109`.

### 5.3 The safety boundary is mostly right

archfit already enforces the most important rule from the prompt:

- **The gate is structurally LLM-free.** `internal/arch_test.go:160-172` forbids `internal/*` packages from importing `internal/llm`.
- **Drafts are inert until approved.** Labels: `internal/labels/labels.go:109-184`. Subdomain/owner/volatility drafts: `cmd/archfit/enrich.go:196-347`.
- **`analyze --llm` is advisory only and runs after the deterministic report.** `cmd/archfit/analyze.go:234-244`; `cmd/archfit/llmreview.go:56-98,448`.

The weak spot is not the boundary. It is the **quality of the evidence pack** given to the LLM before a human pins semantic facts into config.
